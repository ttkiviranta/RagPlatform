The README records an ASP.NET Core Web API foundation with Swagger/OpenAPI, health endpoints, basic project structure, and startup conventions. This was the initial API layer for Rag Platform 2.0.

## Architecture decisions

- Start with a backend-first ASP.NET Core API and establish a small, buildable foundation before adding persistence and domain capabilities.
- Swagger/OpenAPI is the initial interactive API surface.
